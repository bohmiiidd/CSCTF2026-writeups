# Phantom Device

**Category:** Pwn
**Difficulty:** Hard
**Points:** 500

A captured drone from the Vostari military contains an intact mobile communication module. Intelligence analysts at the Meridian Defense Forensics Lab use standard extraction tools to pull data from the module — but the device is not what it seems. Something on the wire is lying about packet sizes.

Your task: develop the payload that the Vostari device would carry. Prove the extraction workstation can be compromised from the wire alone.

**Files:** `client`, `libc.so.6`, `ld-linux-x86-64.so.2`, `libimobiledevice-1.0.so.6`, `libplist-2.0.so.4`

**Flag format:** `CSCTF{...}`
